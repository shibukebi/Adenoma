# Published benchmark results

This directory is for lightweight, reviewable result artifacts:

- `per_fold_metrics.csv`
- `benchmark_summary.csv`
- `RESULTS.md`
- pooled confusion matrices, multi-fold ROC curves and loss curves under
  `figures/`

Raw features, training logs and checkpoints do not belong here. Per-slide
prediction CSVs may contain identifiable slide IDs and should be published
only after the repository visibility and de-identification policy are decided.
